RunnerMaker ｜使い方と設定
このツールの説明書です。
Illustrator 2026向け／Windows・macOS共通。環境によって動作確認が必要です。
※現在大きな処理は変わらないですが、時間はやや長いが安定するもの、時間を短くする代わりに完成が不安定なもの、時間を短くする代わりに動作が不安定なものの3つがあります。

<できること>
選んだ図形をプラモデルのパーツに見立て、外枠と接続棒を作ります。
元の図形は残し、コピーした図形と棒を新しいレイヤへ出力します。
見た目を作るための試作品です。加工用の切断線や強度を保証するものではありません。
自由に使用してかまいませんが、出力が安定しない部分もあるので、完成物をもとに適宜修正してくことを想定しています。


<フォルダ内容>
PREPARATION.txt：最初の準備から生成までの、クリックする場所と手順。
README.txt（このファイル）：設定の意味と、できあがるレイヤの説明。
RunnerMaker.jsx：実行するファイル。中身を編集する必要はありません。

<操作の概要>
各パーツごとにグループ化する → 別名保存 → グループ化したパーツのレイヤを選択 → RunnerMaker.jsxを実行 → プレビュー。
問題なければ、元のパーツを選び直し、同じ設定を入力して「生成」。
デフォルトでは生成時の設定を保存しませんが、「設定を保存」ボタンを押しておくと直近のパラメータを保存できます。
単位はmm／pt／px。変更時は長さの数値も自分で変更してください。
※生成にある程度の時間・負荷がかかるので一時的にIllustratorが応答なしになる可能性が高いですが、操作せず待てば実行が完了します。

<各種パラメータの説明>
子ゲート幅 : 子ゲートはパーツにつながる細い棒の幅です。外枠 (> 幹 ) > 子ゲート > テーパー > パーツの順で接続されます。
幹の幅 : 共通の太い棒の幅です。
外枠の太さ : いちばん外側の枠の太さを表しています。
他パーツ余白 : 他パーツ同士がとる最も小さい余白の距離を指しています。
外枠比率・横 / 縦 : 作成する外枠の比率を決定します。例えば横:3, 縦:2であれば横長になります。
テーパー長 : 先端を細くする区間の長さを決定します。
先端の幅% : 先端が子ゲートからどれだけ短くなるかを決定します。
目標方向 : 上下左右の何方向から支えるかです。本数とは別です。

<各種チェック項目>
近くのパーツ同士も接続する：初期オン。
必要な共有幹を先に作る：初期オン。
生成後に外枠全体を表示する：初期オフ。
  チェックあり＝表示位置・倍率を調整。なし＝現在の表示を維持。
  図形やアートボードの大きさは変えません。
詳細ログを保存する（エラー報告時）：初期オフ。
  チェックあり＝保存先を指定。なし＝ログ用の文字列・処理記録・ファイルを作らず生成。
画面に必要な結果説明やエラーメッセージは、ログがオフでも表示します。
保存の取消・失敗でも通常生成は続きます。
画面ではチェック項目をひとまとめにし、説明文は別の場所に置いています。

<設定の保存について>
「設定を保存」で.txtを保存し、次回「設定を読み込み」で選びます。
自動保存はしません。保存だけでは図形は作られません。
今回の入力・配置・単位・3つのチェックを保存します。ログ項目と絵は保存しません。
旧設定も読めます。枠の幅・高さが0／0なら1：1に、300×200なら300：200の比率に変換。
絶対寸法は維持しません。過去に削除した6項目も自動値へ置き換わります。
従来と同じ形になるとは限りません。保存・読込に失敗しても入力画面へ戻れます。

<注意>
幹・外枠は線、テーパーのゲートは閉じた塗り形です。
4方向には不安定・クラッシュ報告があります。通常は自動・2・3から試してください。
目標方向すべてに向かってゲートを作成できハイ場合は作成できた分のみ出力します。
極端な比率で枠が大きすぎる／座標が不正な場合は、出力前に止めます。
原本の縮小や、他パーツへの強制貫通はしません。
文字・マスク等の接続判定は外接四角形で近似する場合があります。そのため、必ずしも接続されるわけではありません。
比率によっては余白が広くなります。完成寸法は生成後の「詳細」で確認できます。
配置の「自動」は、疎なら維持、密なら群ごとに複製を並べ直します。
詳しい仕様・使い方、不具合は作成者の橋本へご連絡ください。不具合がある際はお手数ですがログを残していただけると原因究明に役立ちます。

<参考:自動で決まる変数>
フチ：片側0.45mm。
枠までの余白：16mmを基本に、太い棒で必要な場合は増やします。
幹の曲がりR：幹の幅×0.6。
外枠の曲がりR：外枠の幅×4/3。小さな枠では収まる範囲へ小さくします。
近接共有の距離：幹の幅×0.8。
最大ゲート長：完成枠の短辺×20%。
  すべてのゲートがこの長さになるわけではなく、接続の上限です。
テーパー長は入力に残ります。「最大ゲート長」とは別の値です。
実際に採用した自動値は生成後の「詳細」で確認できます。
